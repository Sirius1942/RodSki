## 目标范围

v6.7.6 只做契约对齐和回归收敛，不新增第二套用例语法。完成后，RodSki 的源码态、安装态、XSD、核心文档和 `rodski-demo/DEMO/demo_full` 应保持一致。

核心交付：

1. `launch` 可校验、可执行。
2. 旧 model 简化定位器格式被 XSD 和解析器拒绝。
3. SQLite schema 严格校验缺字段和多字段。
4. `type`/`verify` 不再静默跳过数据字段缺失。
5. 接口/DB `_verify` 自引用 `${Return[-1]}` 改为失败。
6. DB verify 不再空比较通过。
7. `run` 路径兼容文档中的 `fun/...` 写法。
8. 打包入口、版本、依赖、schema package-data 统一。
9. demo 迁移方案落地，主验收 demo 清洁。

**内容**

   - 契约变严格，不再静默跳过缺字段。
   - 旧 XML 数据文件不再作为运行时数据源。

   - 接口/DB `_verify` 自引用不再放行。

   - schema / dry-run；
   - 数据文件组织；

   - `_verify` 自引用；
   - model 定位器格式；
   - `run` 路径；

## 风险与兼容策略

1. **严格字段校验会打破依赖缺字段跳过的老用例**  
   处理：先提供 `rodski data validate --strict` 迁移报告；老用例统一补 `BLANK`/`NULL`/`NONE`。

2. **`_verify` 禁止 `${Return[-1]}` 会暴露大量空断言**  
   处理：只对非 UI 模型强制失败；UI 场景中按实际语义单独判断。demo 中先修 `demo_full`，历史 demo 可归档。

3. **打包入口统一可能影响本地开发命令**  
   处理：保留兼容入口一版，但 CI 只认可一个发布入口。

4. **DB verify 字段路径需要稳定约定**  
   处理：v6.7.6 文档明确推荐路径，代码短期兼容旧路径。
