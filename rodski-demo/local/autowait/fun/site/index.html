AutoWait 验收站点（v11.7.0）

每个页面用 ?d=毫秒 控制延迟，d<0 表示永不发生。

  • late_input 输入框 d 后插入
  • late_button 按钮 d 后插入，点击计数
  • disabled_button 按钮 d 后 enabled
  • overlay 遮罩 d 后移除（d=-1 永不移除）
  • hidden_button 按钮 d 后显示
  • async_select 选项 d 后异步填充
  • late_hover 悬停目标 d 后出现
  • late_dblclick 双击目标 d 后出现
  • late_contextmenu 右键目标 d 后出现
  • late_iframe iframe d 后插入
  • chain_form A/B/C 链式出现
  • multi_locator 第 1 个定位器永不命中
  • late_get 文本 d 后出现
  • late_clear 预填输入框 d 后出现
  • late_upload file input d 后出现
  • ready 全部元素立即就绪
